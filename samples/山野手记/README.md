# 山野手记 · 宣传页样例

这些文件是思芽岛宣传页截图使用的演示内容，与网站源码一起长期保留，不含个人文稿或凭据。

| 文件                     | 用途                                       |
| ------------------------ | ------------------------------------------ |
| `01-创作手记.md`         | Markdown 写作和预览                        |
| `02-灵感地图.excalidraw` | Excalidraw 白板                            |
| `03-trail.rs`            | Rust 编辑和语法高亮                        |
| `04-路线数据.json`       | JSON 输入、格式化与输出                    |
| `05-便签墙.md`           | 六张便签，保留颜色、位置、尺寸等原生元数据 |
| `06-TODO待办.md`         | 三级任务、备注和完成状态                   |

前四份可以从独立样例项目中打开；JSON 工具演示需要将 JSON 内容输入工具并执行格式化。Rust 导航需要已安装对应语言服务。

便签和 TODO 属于应用默认空间的专用功能，普通 Markdown 预览不等于加载它们。复现专用界面时应使用隔离的演示环境，分别将样例作为该环境的 `.lance/sticky-notes.md` 和 `.lance/todo.md` 数据。不要直接覆盖日常工作区的同名文件；如需临时替换，先备份，退出相关界面后恢复并核对原文件。

网站仅展示截图，不会读取或改写应用中的便签和待办。页面下载包由 `scripts/package-samples.py` 从本目录生成，包含本说明及全部六份样例。
